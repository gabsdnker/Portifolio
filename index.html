Sobre Mim / About Me

Olá! Sou Gabrielli Danker, estudante de Ciência da Computação no Instituto Federal Catarinense e atualmente atuo na área de Automação de Processos (RPA), onde venho desenvolvendo competências em tecnologias como Power Automate, UiPath, Automation Anywhere e Blue Prism. Minha experiência tem me permitido trabalhar com automação de processos corporativos, integração de sistemas e desenvolvimento de soluções voltadas para ganho de produtividade e eficiência operacional.
Tenho interesse tanto na área de desenvolvimento de software quanto em automação, com foco em linguagens como Java e Python, além de experiência com bancos de dados relacionais (MySQL, SQLite e MariaDB). Busco constantemente ampliar meus conhecimentos técnicos, acompanhando tendências em transformação digital, automação inteligente e desenvolvimento de sistemas.
Ao longo da minha formação, concluí cursos em programação orientada a objetos, lógica de programação, administração de banco de dados e desenvolvimento de sistemas. Também possuo familiaridade com HTML, CSS e JavaScript, além de utilizar Git e GitHub para versionamento e colaboração em projetos.
Sou uma profissional em constante aprendizado, motivada por desafios e pela busca de soluções inovadoras que agreguem valor aos negócios por meio da tecnologia, automação e desenvolvimento de software.

EcoVibe Store

Este projeto é uma loja virtual fictícia voltada para a venda de produtos sustentáveis e ecológicos. Desenvolvido com HTML, CSS e JavaScript, o site conta com sistema de login, carrinho de compras dinâmico, navegação entre páginas e design responsivo. A proposta foi criar uma experiência simples e funcional de e-commerce como forma de praticar conceitos de front-end.


This project is a fictional online store focused on selling sustainable and eco-friendly products. Developed with HTML, CSS, and JavaScript, the website features a login system, dynamic shopping cart, page navigation, and responsive design. The goal was to create a simple and functional e-commerce experience as a way to practice front-end concepts.
